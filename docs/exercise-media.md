# Exercise demonstrations

Most strength guides display both photos from [Free Exercise DB](https://github.com/yuhonas/free-exercise-db), the source Fitlog already uses for its exercise library. The source repository publishes the collection under the [Unlicense](https://github.com/yuhonas/free-exercise-db/blob/b0eed061e1c832b3ed815fbaa4b45b3cdc14df49/LICENSE.md). The photo catalog and image paths are pinned to revision `b0eed061e1c832b3ed815fbaa4b45b3cdc14df49`. Fitlog links to the source for each photo pair.

The machine and cable illustrations attributed to [Open Exercise Illustrations](https://github.com/hitmanrepo/open-exercise-illustrations) use material published under CC0. The assets are derived from revision `2786aefa4b36a08faeca8114e0d1eb0af3ef6732` of the [exercise-images mirror](https://github.com/MarvinNazari/exercise-images). Fitlog resized and re-encoded the WebP files for the viewer. Notes and manufacturer links identify where the illustrated machine differs from the saved exercise.

Fitlog drew the high-foot leg press, prone incline rear-delt fly, single-arm overhead cable extension, and supported loaded calf raise illustrations. Run `node scripts/generate-strength-illustrations.mjs` to regenerate those files.
